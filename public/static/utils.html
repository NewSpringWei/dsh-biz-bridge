RSA-2048 密钥对生成

浏览器本地生成签名密钥对（不依赖服务器）。输入要注册的 Client-Id，输出公钥与私钥： 公钥注册进服务端插件配置 auth.clients[].publicKey；私钥只留在本机， 交给对应工具/客户端使用，切勿外传或提交到代码仓库。

时间转换（开发调试常用）

HTTP API 说明

统一前缀 /bizbridge；除静态页与回调测试接收端点外，全部为 POST + 验签： 请求头携带 X-Client-Id / X-Timestamp / X-Nonce / X-Signature（签名串 = POST + pathname + timestamp + nonce + SHA256(body)， RSA-SHA256 私钥签名）。错误统一返回 {"error":{"code":…,"message":…,"details":…}}； 重复 biz_id 提交返回 409 DUPLICATE_BIZ_ID（幂等演示）。

路径（前缀 /api/v1）所需 scope说明
POST /stream业务级 stream流式响应（SSE）。body：biz_id/session_id/prompt/params；事件帧 start / chunk / reasoning / done(usage) / error；断连即取消。
POST /callback业务级 callback回调响应入队。body：+ callback_url/priority；返回 task_id（status=queued），完成后插件 POST 到 callback_url。
POST /models已注册 client读取 DSH 可用 provider → model → reasoningEfforts（前端联调用）。
POST /tasks/list业务级 / admin任务分页列表（status/type/client_id/biz_id/起止时间筛选）；业务级自动限定自身 client，admin 可跨 client。
POST /tasks/{id}业务级(own) / admin任务详情：prompt/params/result（全文，来自 task_results）/usage/error_message 等。
POST /tasks/{id}/logs业务级(own) / admin任务流水日志分页（received/processing/chunk/completed/failed/cancelled）。
POST /tasks/{id}/cancel业务级(own) / admin取消未开始 / 进行中任务（处理中任务会中止 live agent）；终态返回 400。
POST /tasks/{id}/replay业务级(own) / admin重播：仅已完成处理（成功/失败均可）的回调任务，生成 replay_seq+1 新任务。
POST /tasks/{id}/redeliver业务级(own) / admin再次触发回调：仅 completed / callback_failed 的回调任务；立即重新武装送达并向 callback_url POST 执行结果。
POST /tasks/{id}/priority业务级(own) / admin调整优先级（数字越小越优先，仅 queued）。
POST /stats业务级 / admin运行统计：stream/callback 成功失败、队列、回调送达失败与平均重试；业务级限定自身。
POST /sessions/{id}/messagesadmin会话消息查询（读 DSH session 事件流；需注入 sessionQuery 服务，否则 501）。
POST /callback-test/receive免签名测试接收器（内存 30 分钟 TTL）：回调任务把 callback_url 指向它即可在页面追踪回调到达。
POST /callback-test/{id}需签名查询回调是否已到达测试接收器。

静态页与更完整的协议细节见 code/docs/api.md 与设计文档 docs/dsh-biz-bridge-design.md §6。
