关于这套页面

这是 dsh-biz-bridge 插件的对接参考，同时可作为开发/联调工具。 按使用对象分为三个页面，覆盖插件的两类接口与一组免鉴权小工具：

  • 管理运维：以管理级 client 调用管理接口（统计 / 任务列表 / 详情日志 / 取消 / 重播 / 再次回调 / 优先级 / 会话消息）。
  • 接入测试：以业务级 client 调用通信接口（stream / callback）与业务级自有任务接口（查询 / 取消 / 重播 / 再次回调）。
  • 工具：浏览器本地生成 RSA 密钥对、API 接口说明等免鉴权参考。
需验签 · 管理级

管理运维

运行统计、任务列表/详情/日志、取消、重播、再次回调、优先级调整。

 需验签 · 业务级

接入测试

流式（SSE）与回调提交、业务级自有任务查看 / 取消 / 重播 / 再次回调。

 免验签

工具

RSA-2048 密钥对生成（公钥放进服务端 clients/ 目录）+ HTTP API 说明。

密钥与安全说明

  • 私钥只粘贴在页面顶部文本框，仅存于内存、不写入 localStorage，F5 刷新即清空； 请勿在不可信页面或共享设备上使用。
  • 公钥存成服务端数据根下的 clients/<clientId>.pem，并在 clients/clients.json 里登记 scope；改动即时生效，无需重启。
  • 页面为纯静态参考实现：验签在浏览器完成，私钥不会离开你的浏览器。
